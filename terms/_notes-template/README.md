# Notes template

Copy this folder's `_template.md` into your own term when you start a week:

```
terms/2026-2027-fall/notes/week-01.md
```

One file per week, named `week-01.md` … `week-14.md`, matching the files in
`weeks/`.

Everything under your term folder is **yours**. The shared plan in `weeks/` is
not — if the course changed, fix it there so the next person gets the corrected
version.
